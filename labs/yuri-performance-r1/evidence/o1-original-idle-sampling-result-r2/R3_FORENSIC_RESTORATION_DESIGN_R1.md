# R3 forensic restoration design — file-only, not execution approval

R2 failure is preserved; full145/four-domain/all137/allKey+driver/native geometry scope and all gate strictness remain required. This document is a design, not an executable packet or approved diagnostic. No R3 collector or launcher has run.

Evidence locations: frozen collector r4_original_idle_sample_r2.py stores before bindings through props(animation_data) in ORIGINAL_BINDING_KEY_INPUTS_PRIVATE_R1.json, then saves original Action/slot/existence in resolved rows; finally only sets action and, if non-null, action_slot before restoring properties/transforms/Key values/frame. The failed snapshot is generated by r4_appearance_signature.py: objects include props/custom/anim/modifiers/constraints/material slots/groups/pose; mesh_attributes include mesh props, vertex attributes and Key props/anim/blocks. Thus every one of the four target AnimData owners appears in the exact changed fingerprint scope, but these hashes cannot isolate an individual field.

Concrete omission: before last_slot_identifier='' is durable; this field is not explicitly restored. Original action_slot_handle0 is captured but restoration relies on implicit API behavior. Neither field's final native value was recorded. Do not claim either caused the observed differences, classify them transient/cosmetic, or remove them from the existing signature. Preserve exact NLA structure, including FACE SEC5H_PREVIEW muted track and null-action CLIP/influence0.

R3 must capture full deterministic raw inputs used by each original fingerprint at three phases: OFF baseline, ON at original saved frame, and restored OFF at identical frame/subframe. Keep numeric/private payload separate from public path-only differences. Capture all owner AnimData RNA fields, direct bindings/slot identifiers/handles/last_slot_identifier/tweak storage/use_nla/pin, recursive NLA track/strip RNA, drivers/Fcurve RNA and variables, object/pose custom fields and transform channels, Key/KeyBlock properties and values, mesh property/attribute state and evaluated-cache fingerprints. Capture custom-property UI metadata separately to diagnose read-side changes; retain unknown units/defaults. Reuse the exact original serializer exclusions and hash algorithm, and prove emitted raw input recomputes each affected hash. A second narrower serializer cannot establish why the original full signature differs.

Rollback ledger: before touching a target, record owner existence and original AnimData object, all writable original AnimData settings, original Action and exact slot/handle/last_slot_identifier, all touched primitive RNA/custom values, all object/pose transform and rotation_mode/custom states, all original Key values, scene frame/subframe and original NLA/driver graph. Restore original binding first, then explicit writable bookkeeping fields, original custom/Key/pose states and frame in a documented order; record each attempted assignment/readback and exception. Verify read-only fields against original rather than force them. Do not create/delete existing AnimData, alter driver expressions/NLA or clear/rebuild them to suppress a difference. Restore no-action targets' original saved slot metadata explicitly if the native API permits; if unsupported, stop and report the unresolved exact field rather than waive it.

After restoration, write raw after-state, field-level comparison and structural ledger **before** the PASS assertion so a legitimate failure retains complete diagnostic evidence. Keep final signature assertion strict. Record raw driver invalid/mute and evaluation flags without claiming they are incidental. On exception, preserve both the original error and every restoration error; do not mask the original traceback with a later assertion. Source file/pre-post input SHA, GUI/GPU lease and strict owned Job remain separate from in-memory preservation.

ON allowed-change ledger: only the four explicit QA Action/slot assignments, their animated property/Key values and evaluated pose/geometry can differ in memory. Geometry source/rest/weights/materials/textures/original curves/modifiers and driver/NLA structural definitions must match. Full structural/read-only fields get individual pre/ON/after receipts. Endpoint and seam assessments must include all saved native orientation matrices, driver outputs and full geometry; scalar/head vectors alone cannot certify closure.

Before any native R3 diagnostic or sampling, create additive immutable code/config/argv/hash/receipt template and rollback packet for exact PM review. Keep CPU2threads/affinity3/8GiB/120s/RAM12GiB/C100GiB/installed315,strict LIVE/whole Job cleanup,one attempt/no retry and closed-log final custody. If an independent read-only diagnostic is necessary, propose it as a separate exact scope; it cannot silently activate Actions. No R2 receipt reuse, native build/download/export/render/save/unmute or source overwrite.
