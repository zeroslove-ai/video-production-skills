# YouTube Content Studio — R0 사업 검토 및 콘텐츠 전략
작성: 2026-10-18 (KST) | 상태: 제안 / 미승인 / 배포 없음

## 0. 목적과 현재 판정
- 기존 Video Production Skills + Video Motion Production Skills + 사용자가 보유한 ComfyUI/로컬 비디오 제작 환경을 활용해, 영상 연구 → 기획 → 제작/편집 → QA → 배포 → 성과 학습을 재사용 가능한 시스템으로 구축한다.
- 1차 아이디어: (A) 저작권이 정리된 고전 동화를 자체 각색하여 밝은 아동용·차분한 잠자리용 롱폼과 파생 숏츠를 제작한다. (B) 성과가 높은 롱폼의 **주제/구조**를 조사하고, 자체 제작/정식 허락된 영상에 한해 하이라이트 숏츠를 제작한다.
- **기술적 가능성: 높음. 광고수익 실현 가능성: 미검증.** '조회수 높은 타인 영상 수집 → 자막만 붙여 대량 재업로드'는 기본 제품 모델에서 제외한다.
- 현재 GitHub 자산은 시스템의 기반이지, 바이럴 영상 발굴·권리 심사·숏츠 공장·업로드가 이미 연동됐다는 증거가 아니다. 이 문서는 작업 착수용 R0 초안이다.

## 2. 콘텐츠·수익 모델 우선순위
| 모델 | 원본/이용 권한 | 자동화 적합성 | 정책·저작권 위험 | 권장 |
| --- | --- | --- | --- | --- |
| 고전 동화 자체 각색 + 자체 영상(한국어/영어) | 원작과 현대 번역·삽화 구분 검증, 생성 에셋 권리 정리 | 높음 | 상대적으로 관리 가능 | **1순위: 자체 IP** |
| 자체 롱폼 또는 직접 촬영/제작 영상의 숏츠 파생 | 완전 보유 | 매우 높음 | 낮음 | **1순위: 즉시 기술 MVP** |
| 크리에이터와 서면 계약한 공식 클립 제작 | 파생편집·상업·플랫폼 권한 문서화 | 높음 | 계약/음원 확인 필요 | **2순위: B2B 제작·매출배분 실험** |
| 인기 롱폼을 '아이디어 출처'로만 연구, 자체 대본과 시각자료로 새 영상 | 타인의 영상 재사용 금지 | 높음 | 표절/오인 방지 검수 | **2순위: 트렌드 리서치 채널** |
| 타인의 인기 영상을 무허락 다운로드해 자막/크롭 후 재업로드 | 불명확/없음 | 기술적으로 쉬움 | 높음. 재사용 콘텐츠 수익화 제한 가능 | **실행하지 않음** |

수익원 가설: 유튜브 YPP 광고/Premium(조건 충족 후), 자체 IP 장기 활용, 허락 받은 크리에이터 대상 클립 편집 B2B, 적합 시 스폰서십. 초기 30일에는 수익 목표가 아니라 권리·품질·제작 단가와 시청 반응을 확인한다. 영상당/1000뷰당 수익을 확정값으로 추정하지 않는다.

## 3. 채널 구조와 숏츠 역할
- 채널 A(아동용): 밝은 4~8분 동화 / 잠자리 8~15분 동화 / 각 본편당 4~6개 독립적 가치가 있는 15~45초 숏츠 후보. 교육·잠자리 특성에 맞는 연출 분리.
- 채널 B(일반 콘텐츠): 트렌드 기반 자체 해설/분석 숏츠 또는 계약 제작 클립. 실험이 유효해진 뒤 별도 채널로 시작하며, 아동용과 시청자·분류를 혼합하지 않는다.
- 숏츠 목적 = 발견/관심 유도. 숏츠 시청자가 실제 본편을 시청하는지 별도 측정한다. '조회수가 많으면 본편 전환된다'고 가정하지 않는다.
- 아동용 콘텐츠는 YouTube Made for Kids 분류, 맞춤광고 제한, 댓글·엔드스크린 등 기능 제한을 반영한다.

## 4. 트렌드 발굴이 의미하는 것
- 후보 검색에는 승인된 YouTube Data API 등 허용된 메타데이터 접근을 사용한다. 키워드/카테고리, 최근 업로드, 공개 조회수, 영상 길이, 채널 규모·최근 업로드 수치(취득 가능한 경우)를 수집한다.
- 임의 점수(실험용): 최근 기간의 조회수 증가 추정 + 채널 자신의 최근 영상 대비 상대 성과 + 시의성 + 사용자 타깃 적합도 + 직접 재창작 가치. 공개 조회수/게시 시간만으로 광고수익이나 실제 유지율을 추론하지 않는다.
- 결과물은 '인기 동영상 다운로드 목록'이 아니라 **주제·서사 구조·창작 방향에 대한 리서치 카드**다. 제3자 동영상은 권리 확인 전 편집 자산에 반입하지 않는다.
- 원본 파일이 필요하면 소유자가 직접 보유한 파일, 적법하게 제공한 소스 파일, 별도 상업적 이용권이 검증된 자료만 수령한다. YouTube API를 영상 다운로드·음원 추출 우회에 사용하지 않는다.

## 5. 반드시 분리할 권리 심사
각 원본에 source URL / title / creator / ownership class / permission evidence / permitted uses / commercial use / derivative work / platforms / territories / term / music/performer clearance / attribution / reviewer / expiry / checksum을 기록한다.
- OWNED: 우리 원본. 원본/음원/출연 관련 권리 모두 확인.
- PARTNER_LICENSED: 권리자가 직접 제공한 파일 + 서면 계약, 편집·상업·Shorts·각 플랫폼 허용 확인.
- PUBLIC_DOMAIN_VERIFIED: 해당 국가와 버전별 퍼블릭 도메인 검증. 고전 이야기 원작과 최근 번역, 그림, 음악은 별개.
- THIRD_PARTY_REFERENCE_ONLY: URL·메타데이터로 주제 연구만 허용. 음영상 반입/재업로드 금지.
- UNKNOWN / REJECTED: 제작 파이프라인 차단.

**주의: 원저작자 허락과 YouTube '재사용된 콘텐츠'의 광고수익화 적격성은 별개다.** 별도 해설·새로운 서사·실질적 편집 및 원작성 판단이 필요하고 자동 보장되지 않는다.

## 6. 자동화 단계
1. Discover: 공개 메타데이터 기반 인기 콘텐츠/주제 발굴 → 추천 이유/출처 로그.
2. Rights Gate: 자체·계약·검증된 퍼블릭 도메인 원본만 실물 수입/처리.
3. Understand: 소유·허락된 음영상의 음성 인식, 장면 구분, 타임코드, 정보/감정 포인트 추출.
4. Script/Select: 하이라이트 3~5개, 독립적인 가치·맥락·추가 해설이 있는 대본 제작.
5. Produce: 세로 9:16 리프레이밍, 컷 편집, 자막, 필요한 원본 2.5D 그래픽/ComfyUI 장면, 음원 사용권 검수.
6. QA: 권리, 아동용 표시, 인용 맥락/팩트, 시각·음질·안전영역, 반복·유사도, 썸네일·메타데이터, 에셋/출력 해시 확인.
7. Publish: 우선 로컬 산출물. YouTube OAuth/채널 권한 승인 후 비공개 업로드 → 사람 승인 → 예약 공개. **무승인 자동 공개 금지**.
8. Learn: 24h/7d/30d 자체 채널 조회수·유효 조회수/시청시간·구독·숏츠↔본편 겹침·제작시간·재생성 비용. 데이터 권한 범위 내에서만 측정.

## 7. 수익화와 플랫폼 정책 — 2026-10-18 조사 시점
- YouTube는 2025-07-15에 반복·대량 생산된 'inauthentic content' 범주를 더 명확히 했고, 단순 컷·자막 재사용만으로는 수익화가 제한될 수 있다. AI 도구 사용 자체는 자동 실격이 아니다.
- 현재(2026-10-18) 광고/Premium YPP 기본 진입 기준: 구독자 1,000명 + 최근 12개월 적격 시청 4,000시간 **또는** 최근 90일 적격 Shorts 조회수 1,000만 회(기타 심사 필요). Shorts 피드 조회 시간은 롱폼 4,000시간에 합산되지 않음.
- **2027-02-01부터 신규 신청자 기준 강화 예정:** 구독자 1,000명 + 최근 365일 적격 시청 8,000시간 또는 최근 90일 Shorts 적격 조회수 2,000만 회. Shorts Creator Pool 수익에도 월별 기준으로 직전 90일 1,000만 적격 조회수 유지 요건을 발표함. 실제 적용 시점과 채널 자격은 출시/가입 직전에 다시 확인.
- 아동용은 맞춤광고가 꺼지고 댓글, 카드, 최종화면 등이 제한된다. CTR/쇼츠 전환 전략에 이런 한계를 반영.
- 실사와 혼동 가능한 AI 생성/변경 콘텐츠는 플랫폼의 synthetic/altered disclosure 정책 준수. 동화 애니메이션과 뉴스·실사형을 동일하게 다루지 않음.

## 8. 첫 30일 MVP (예정, 아직 실행되지 않음)
- Week 1: 기존 두 영상 저장소와 로컬 ComfyUI/영상 편집 런타임을 **읽기 전용으로 조사**. 메타데이터 검색 시제품, 권리/출처 후보 기록 포맷, 공개영상 20개 주제 후보만 수집.
- Week 2: 직접 만든 또는 사용권 확인된 **하나의 5~10분 원본**에서 20~45초 숏츠 3종 기획, 타임코드 정확성 확인. 그중 2~3개 렌더링. 외부 인기 영상 무단 추출 금지.
- Week 3: 짧은 영상 품질 QA, 9:16·캡션·음량·권리 로그 PASS. 아동 동화 밝은/잠자리 버전 중 한 장면을 별도 스모크 테스트.
- Week 4: 채널/API 연결 권한과 사용자의 실제 공개 승인 확보 시 비공개 업로드 및 예약 테스트. 승인 없으면 MP4+메타데이터까지만 완성.
- 가설 검증 KPI: 권리 불명 콘텐츠 업로드 0건, 렌더 오류 0건, 승인 숏츠 ≥3편, 재현 가능한 편집 프로젝트/원본 경로, 숏츠당 제작시간·API 비용 측정, 실제 공개 시 유효 조회수·시청 유지율·본편 전환 추적.
- Gate R0: 적법한 원본 확보 및 작업 환경 조사 결과 없이는 '공장 READY' 선언 금지. Gate R1: 재현 가능한 자체 원본→3숏츠 렌더와 수동 QA. Gate R2: 최소 2주 시청 데이터로 콘텐츠/채널 전략 재평가.

## 9. 해야 할 일 / 하지 말아야 할 일
- 해야 할 일: 콘텐츠별 출처와 권리 근거를 남기고, 실패한 장면만 재생성, 숏츠별 차별화된 서사/내레이션을 제작하며, 사용자가 제어할 수 있는 승인 게이트 운영.
- 하지 말아야 할 일: 인기 유튜브 영상 무단 다운로드/복제, 가짜 수익 증명에 따른 투자, API 약관 우회, 콘텐츠마다 배경만 바꾸는 양산, 공개 전 검수 우회, 유료 API 및 계정/키 무승인 호출, 아동용 콘텐츠를 일반용으로 잘못 표시.
- 새 채널 생성/업로드/광고 신청/외부 계약 체결은 이 문서만으로 자동 승인되지 않는다.

## 11. 결정 대기 사항
- R0는 연구·문서·비공개 로컬 테스트 범위에 한정. 기존 main 및 동작 중 파이프라인 유지.
- 1차 공통 엔진은 '자체 원본 편집'을 우선 제작하고, 권리 승인 완료 원본만 파이프라인에 추가.
- 일반 숏츠 채널의 주제·브랜드·수익배분 계약은 성과 데이터와 함께 별도 제안/판정.
