## 확보 후 분석할 항목 — 아직 결과 아님

1. **원본 확인:** 접근 가능한 원본 또는 사용자가 제공한 MP4를 연구용 로컬 폴더에 보관. SHA-256, 길이, 스트림, 파일 크기와 출처를 기록한다. DRM/유료 장벽 등 접근 통제를 우회하지 않는다.
2. **장면 단위 관찰:** 시작·끝과 화면 변화 지점의 대표 프레임을 확인하고, 각 장면의 타임코드와 화면에 보이는 도구/입력/결과를 연결한다. 저해상도 화면의 작은 글씨는 미확인으로 남긴다.
3. **음성 검증:** 확보된 오디오를 전사하고 핵심 설명/금액/시간/도구명은 실제 음성과 대조한다. 영상 화면만 봤으면 오디오 검증을 했다고 말하지 않는다.
4. **실제 흐름 분해:** 인기 영상 탐색 → 소스 확보 → 요약/컷 선정 → 세로 편집/자막 → 검수 → 업로드 중 어떤 단계가 실제 실행됐는지 분리한다.
5. **자동화 수준:** 한 번 클릭한 결과인지, 수동 선택/복사/로그인/승인/재시도가 편집으로 생략됐는지 확인한다. 화면 속 워크플로 선 연결은 성공 실행의 증거가 아니다.
6. **수익 증거:** 기간, 대상 채널, 광고/제휴/강의/편집 대행 등 수입원, 비용 포함 여부를 분리한다. 화면의 수익 숫자만으로 사실을 인증하지 않는다.
7. **재사용 판단:** A/B/C 각각에 채택할 부분, 우리 기존 ComfyUI/Remotion/FFmpeg로 대체할 부분, 필요 없는 유료 의존성, 별도 검증 사항을 정리한다.
