## 1. 이번 사용자 결정

다음 세 가지를 모두 병렬로 준비한다. A를 위험하다는 이유만으로 연구 대상에서 제외하거나, A를 B로 바꾸어 보고하지 않는다.

- **A — 타인의 인기 롱폼을 잘라 숏츠 제작:** 원본의 영상·발언을 실제 컷 편집하는 모델.
- **B — 인기 주제를 발굴하고 자체 해설·영상 제작:** 인기 콘텐츠는 수요 조사에 활용하고 대본·내레이션·시각자료는 새로 제작하는 모델.
- **C — 직접 제작한 동화·애니메이션을 숏츠화:** 밝은 동화와 차분한 잠자리 동화를 만들고 각각 숏츠로 연결하는 모델.

R0의 일렬 우선순위 및 A 전면 제외 제안은 이 문서로 대체한다. R0 문서들은 이전 검토 기록으로 보존한다. 세 트랙의 준비가 승인된 것이지, 임의 채널 공개·유료 구독·외부 계약·무제한 GPU 작업까지 승인된 것은 아니다. 실제 담당 에이전트가 시작했다는 증거 없이 RUNNING으로 표시하지 않는다.

## 2. 공통 엔진 하나 + 콘텐츠 실험 세 개

공통 기능: 출처/원본 등록 → 타임코드·장면 분석 → 대본/컷 계획 → 세로 편집·자막·오디오 → 검수 → 승인 큐 → 성과 기록.

- video-production-skills: 전체 기획, 출처 관리, 편집·합성, 배포 설계와 기록.
- video-motion-production-skills: 모션그래픽·2.5D·자막/도형 렌더링. 저장소를 합치지 않는다.
- 기존 ComfyUI: B/C의 새 그림·장면 제작에 선택적으로 사용. A의 단순 컷 편집에는 무조건 생성 모델을 끼워 넣지 않는다.
- 연구·대본·컷 계획은 독립적으로 병렬 준비한다. 실제 GPU 렌더는 기존 작업과 충돌하지 않는 공용 큐를 사용한다.
- 공통 파일 writer는 1명, 트랙별 문서/작업 디렉터리는 분리한다. 독립 QA는 읽기 전용이며 수정은 원래 담당자에게 돌린다.

## 3. A — 인기 롱폼 클립형

### 첫 준비물
1. 후보 롱폼 10개: URL, 제작자, 게시일, 조회 확인 시각, 길이, 주제, 상대 성과의 근거, 이용 조건.
2. 우선 후보 1편의 맥락 요약과 컷 후보 5개: 시작/끝 타임코드, 선택 이유, 앞뒤 발언, 오해 위험.
3. 적법하게 확보하고 사용할 수 있는 원본으로 20~45초 세로 숏츠 시제품 3개: 서로 다른 핵심 내용, 자막, 피사체 구도, 오디오 검수.
4. 기술 성과와 공개 가능성을 각각 판정한 기록.

### 연구와 공개를 분리
- 권리 상태가 미확정이어도 공개 정보 조사, 컷 구성 연구, 템플릿 개발은 계속할 수 있다.
- 사용자가 지정한 참고 영상의 열람·분석용 확보 요청과 상업적 클립 재배포 승인은 동일하지 않다. 연구용 자료는 공개 배포 자산과 분리한다.
- 원본 취득은 허용된 접근/제공 경로에서 수행한다. 접근 통제·DRM·유료 장벽을 우회하지 않는다. 비공개라는 이유만으로 이용 권리가 자동 해결된다고 판단하지 않는다.
- 공개 전에는 영상·음원·출연/이용 범위 및 저작권 검토와 YouTube 재사용 콘텐츠 적격성을 각각 검토한다.
- 단순 크롭·자막·배속 변경만으로 수익화가 보장된다고 주장하지 않는다. 원작자 허락도 YouTube 수익화 심사와 별개다.[1]
- 방송/스포츠/영화의 인기만 보고 시범 공개부터 하지 않는다. 공개에 필요한 근거가 부족하면 해당 출력만 보류하고 A의 연구 및 B/C는 계속한다.

## 4. B — 인기 주제 자체 해설형

### 첫 준비물
1. 인기 주제 후보 10개와 각 주제의 원출처·최근성·시청자 질문을 정리한다.
2. 한 주제에 서로 다른 관점의 30~60초 대본 3종: 무엇이 달라지는지, 직접 설명할 가치, 확인 가능한 사실을 표시한다.
3. 자체 내레이션 + Remotion 그래픽/직접 만든 시각자료로 첫 시제품 1개를 목표로 한다.
4. 정보마다 근거와 확인일을 남긴다. 원본 발언이나 줄거리의 단순 치환이 아니라 질문·구조·해설을 새로 설계한다.

공개 타깃은 일반 시청자다. 초기 후보는 직접 화면/작업 결과를 보여줄 수 있는 도구 사용·제작 과정·일상 호기심 중심으로 제안한다. AI가 실제 전문가인 것처럼 민감한 분야의 조언을 제공하는 구성은 도입하지 않는다. 주제는 제안이며 실제 후보 10개가 이미 조사됐다는 뜻은 아니다.

## 5. C — 자체 동화·애니메이션형

### 첫 준비물
1. 신데렐라 한 편의 권리 확인 대상 원전, 자체 각색 줄거리, 캐릭터·색감·의상 기준을 정리한다. 최근 번역·삽화·음악을 원작과 혼동하지 않는다.
2. 같은 한 장면으로 밝은 버전과 차분한 잠자리 버전의 45~60초 대본·스토리보드를 각각 작성한다.
3. 각 버전에서 15~30초 독립적인 미니 이야기 숏츠를 1개씩 계획한다.
4. 레이어 기반 모션을 기본 후보로 삼고 꼭 필요한 장면만 생성 영상으로 보완한다. 캐릭터 일관성·이야기 이해·음성 품질·놀라게 하는 소리/섬광을 검수한다.
5. 잠자리 버전은 단순 배속·색상 변경이 아니라 낭독·쉼·전개를 다르게 설계하고 오디오 중심 이용도 고려한다.

본편 6개를 먼저 대량 렌더하지 않는다. 짧은 장면으로 품질과 비용을 확인한 뒤 기존 3동화×2버전 계획의 확대 여부를 정한다. 아동용 표시와 해당 품질 기준은 별도 검수한다.[1]

## 6. 비교 기준 — 수익 순위를 미리 정하지 않는다

위의 편수·길이·후보 개수는 내부 파일럿 목표이며 업계 평균 또는 플랫폼 권장 수치가 아니다.

| 항목 | 공통 기록 | 해석 |
|---|---|---|
| 제작 공수 | 사람 수정 분, 모델/API 비용, GPU 사용 분, 재렌더 횟수 | 원본 확보/권리 검토 시간도 빠뜨리지 않는다 |
| 결과 품질 | 이해 가능성, 자막/문맥/음질, 시각 일관성 | 자동 검사 통과와 실제 시청 품질을 구분한다 |
| 공개 가능성 | 원본/에셋 이용 근거, 플랫폼 검토, 사람 승인 | 다운로드 성공은 공개 권한의 증거가 아니다 |
| 실제 시청 | 공개 후 동일 경과 기간의 유효 조회·시청 유지·재방문 | 공개 전에는 null. 타인 영상 수익/유지율을 추측하지 않는다 |
| 본편 연결 | 숏츠와 본편 시청자 중복 및 파악 가능한 유입 | 전체 조회수를 곧바로 전환으로 보지 않는다 |
| 수익 | 광고 등 실제 정산, 별도 수입, 모든 제작 비용 | 강의/제휴 수입과 채널 광고 수입을 구분한다 |

세 트랙의 관찰 표본이 작으면 우열을 확정하지 않는다. 수익화 조건은 공개 직전 공식 문서와 실제 채널 상태를 재확인한다. A/B 일반 콘텐츠와 C 아동 콘텐츠는 브랜드·대상 시청자를 섞지 않도록 설계하되 채널을 지금 자동 생성하지 않는다.
